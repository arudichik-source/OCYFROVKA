# Технічне завдання — «ОЦИФРОВКА»

**Версія ТЗ:** 0.1  
**Дата:** 07.10.2026  
**Статус:** базове затверджене ТЗ

## 1. Мета

Створити окрему портативну Windows x64 програму для локального оцифрування фотографій, сканів і PDF-документів із відновленням структури таблиць, перевіркою результату та експортом у Excel.

Основний сценарій: `фото/PDF → покращення зображення → OCR → відновлення таблиці → перевірка → підтвердження → XLSX`.

## 2. Обов'язкові обмеження

- Без обов'язкового Інтернету.
- Без OpenAI/Google/Azure/Hugging Face API та без API-ключів.
- Без регулярних платежів.
- Без окремого встановлення Python, Java, Tesseract, .NET Runtime, SQLite або Visual Studio на робочому ПК.
- Без прав адміністратора та UAC elevation.
- Без запису в HKLM, реєстрації системних DLL або Windows service.
- Запуск із розпакованої портативної папки.
- Реальні документи за замовчуванням нікуди не передаються.

## 3. Технологічна база

- C# / .NET 10 / WPF.
- Self-contained Windows x64 deployment.
- Tesseract 5.x як перший локальний OCR engine.
- `ukr.traineddata`, `eng.traineddata`, `osd.traineddata` у портативній поставці.
- OpenCV/OpenCvSharp або еквівалент для preprocessing.
- SQLite для локальної бази.
- XLSX як основний формат експорту.

## 4. Архітектура

`Input → ImagePreprocessor → DocumentDetector → LayoutAnalyzer → IOcrEngine → TableReconstructor → SmartCorrector → ValidationEngine → Review → Export`

OCR не змішується з бізнес-логікою. Рушій підключається через `IOcrEngine`, щоб надалі можна було додати інший локальний OCR без переписування UI та документної логіки.

## 5. Функціональні вимоги

### Вхід
- JPG, JPEG, PNG, BMP, TIF/TIFF, PDF.
- Drag & Drop та звичайний вибір файлів.
- Кілька фото можуть утворювати один документ.
- Зміна порядку, поворот, видалення та додавання сторінок.

### Preprocessing
- автоповорот; deskew; perspective correction; crop;
- grayscale, threshold, contrast, sharpen, noise/shadow reduction;
- оригінал не знищується; доступне порівняння з обробленим зображенням;
- кілька варіантів preprocessing і оцінка якості фото.

### OCR і таблиці
- українська як основна мова, `ukr+eng` для змішаних документів;
- збереження координат і confidence;
- відновлення рядків і колонок не лише за послідовністю OCR;
- окремі правила для числових полів;
- контекстні, а не глобальні заміни схожих символів;
- повторний OCR окремої області/поля.

### Довідник і виправлення
- локальний довідник затверджених найменувань;
- normalisation + fuzzy matching + token matching;
- числові частини та калібри мають підвищену вагу;
- сумнівні виправлення лише пропонуються;
- ручні підтвердження запам'ятовуються локально.

### Перевірка
- оригінал поруч із структурованим результатом;
- статуси Recognized/Suggested/Corrected/Confirmed/Error;
- OCR, validation, dictionary та final confidence;
- перевірка пропусків, чисел, дублікатів, невідомої номенклатури і низької впевненості.

### Експорт
- основний формат XLSX; додатково CSV/TXT;
- кількість залишається числом;
- Unicode/українська зберігається коректно;
- автоназва з можливістю редагування.

## 6. Портативна структура runtime

```text
ОЦИФРОВКА/
  ОЦИФРОВКА.exe
  Engine/OCR/tessdata/
  Data/
  Workspace/Input/
  Workspace/Temp/
  Workspace/Processed/
  Export/
  Logs/
  Config/
```

Програма сама створює відсутні робочі папки. База, Workspace, Export, Logs і приватні словники не зберігаються в публічному Git.

## 7. UI і стабільність

Темний сучасний WPF-інтерфейс без мерехтіння. Розділи: Нове оцифрування, Черга, Перевірка, Готові, Історія, Довідники, Шаблони, Налаштування.

Тривалі операції виконуються асинхронно. Передбачити autosave, відновлення незавершеної сесії, технічний лог без повного змісту документів і self-test першого запуску.

## 8. Критерій портативності

На робочому Windows-ПК: розпакувати ZIP → запустити EXE → відкрити документ → OCR → редагування → XLSX. Якщо для цього потрібно окремо встановити програму або отримати права адміністратора, критерій не виконаний.
