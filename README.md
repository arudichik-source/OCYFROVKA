# OCYFROVKA

**ОЦИФРОВКА** — безкоштовна локальна Windows-програма для оцифрування фотографій, сканів і PDF-документів.

## Базові принципи

- Windows x64, C# / WPF / .NET 10.
- Портативна self-contained збірка: встановлення .NET та прав адміністратора не потрібно.
- Робота з документами локально, без обов'язкового Інтернету, API-ключів або платних OCR-сервісів.
- OCR-архітектура модульна: перший рушій — локальний Tesseract 5.x.
- Реальні документи, локальні бази, журнали та робочі файли не повинні потрапляти у Git.

## Поточний стан

**Stage 1 — Bootstrap.** Створено WPF-каркас, портативну структуру робочих папок, базові доменні контракти, перші тести та автоматичну Windows-збірку GitHub Actions.

Наступні етапи: імпорт JPG/PNG/PDF → preprocessing → Tesseract OCR → відновлення таблиць → перевірка → довідники → SQLite → XLSX.

## Збірка

GitHub Actions формує артефакт `OCYFROVKA_Portable_x64.zip` на стандартному Windows runner.

Локальна збірка для розробника:

```powershell
./build/Build-Portable.ps1
```

Готова програма запускається через `ОЦИФРОВКА.exe` із портативної папки.
